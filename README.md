# 🎯 AI Career Path Navigator

An AI-powered career recommendation system developed as part of the **CodSoft AI Internship**. The application recommends suitable career paths based on the user's skills using **Natural Language Processing (NLP)** and **Cosine Similarity**.

## 🚀 Live Demo

🔗 https://aicareerpathnavigator.streamlit.app

## 📌 Features

- 💡 AI-based career recommendation
- 🧠 NLP-powered skill matching
- 📊 Cosine Similarity for accurate recommendations
- 🎨 Clean and interactive Streamlit interface
- ⚡ Instant career suggestions

## 💻 How It Works

1. Enter your skills.
2. The application preprocesses the input.
3. NLP converts skills into numerical vectors using **CountVectorizer**.
4. **Cosine Similarity** compares your skills with different career profiles.
5. The most relevant career recommendations are displayed along with their matching percentage.
